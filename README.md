# OOP Billing System — Python Week 3 Project

## 📌 Project Overview
This repository contains an **Object-Oriented Billing System** developed for the **Week 3 Python Programming** assignment[cite: 35]. It models real-world object interactions to compute item totals, tax percentages, and print tabular billing receipts[cite: 35].

---

## 🛠️ Architecture & Classes
* **`Product` Class**: Stores `name`, `price`, and `quantity` with methods to calculate itemized totals[cite: 35].
* **`Bill` Class**: Manages a list of `Product` objects, computes subtotal, applies tax (5%), and renders formatted tabular invoices[cite: 35].
